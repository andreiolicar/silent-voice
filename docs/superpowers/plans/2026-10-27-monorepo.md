# Silent Voice Monorepo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Consolidar site, API, admin, mobile e espaço de IA em andreiolicar/silent-voice preservando produção e histórico.

**Architecture:** npm workspaces em apps/* e packages/*. Frontends separados montados em dist/index.html e dist/admin/index.html; API usa contratos sem importar fontes da landing; IA tem ambiente próprio.

**Tech Stack:** Node24/npm11, React19.3/Vite8, Fastify5/BetterAuth1.7.14/pg, Expo57/RN0.86.3/React19.2.3.

**Spec:** docs/superpowers/specs/2026-10-27-monorepo-design.md

## Global Constraints

- Nenhum segredo, backup, banco ou dataset no Git; preservar versões e SQL.
- Preservar commits originais e todo o working tree mobile; não modificar clones de origem.
- Manter URLs, dois Render gratuitos, Neon, segredos e sessões.
- IA não fornecida: organizar contribuição, sem simular implementação.

## Review Focus

- Resolução de React web dentro do mobile ou múltiplos React no mesmo frontend: testar versões/caminhos e exports.
- /admin e /conta servindo HTML da landing: testar montagem e seleção de documento/rewrite.
- API importando frontend ou dependências transitivas: testar runtime a partir do workspace e exports de contracts.
- Snapshot/histórico perdidos: comparar manifestos de hashes e commits ancestrais.
- Corte Render alterando env/cookies/SQL: salvar configuração, comparar SQL e verificar sessão/2FA sem revelar credenciais.
