# Silent Voice Mobile

Fundação mobile do Silent Voice construída com React Native, Expo e TypeScript.

## Comandos

```bash
npm install
npm start
npm run android
npm run ios
npm run lint
npm run typecheck
```

A rota atual é apenas uma verificação da fundação. Consulte `docs/architecture.md` e `docs/design-system.md` antes de adicionar features ou telas.
