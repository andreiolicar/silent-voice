# @silent-voice/site

Landing e assistente comercial, com React/Vite/Motion. Responsiva, com assets locais, splash e dispositivo interativo preservados.

Instale na raiz do monorepo e execute `npm run dev:site` ou `npm run dev` para os três serviços web. API fica em `apps/api`, administração em `apps/admin`; controles e tokens compartilhados em `packages/web-ui`.

O prebuild gera a marca da splash e a especificação OpenUI. O build combinado da raiz inclui a administração em `dist/admin`. Leia o [README principal](../../README.md) e [interfaces web](../../docs/web-ui.md).
